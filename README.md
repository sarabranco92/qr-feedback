# QR Feedback

A small feedback application for businesses, built around shareable review URLs and an administrator dashboard.

**Python · FastAPI · SQLite · Jinja2**

[Setup and technical guide](docs/PROJECT_GUIDE.md) · [Contact Sara](mailto:sbdev42@gmail.com)


## Purpose and features

- Public business review forms with rating, comment and optional contact email
- Low-rating flags and an authenticated dashboard
- Review filtering, seen status and CSV export
